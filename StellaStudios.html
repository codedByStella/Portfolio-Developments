Turn a creative brief into an assembled video

StellaStudios connects structured creative instructions to video generation, synthetic narration, soundtrack selection, subtitles, and FFmpeg-based assembly. Its goal is to reduce repetitive editing work by coordinating the steps that turn separate media assets into one short-form video.

overview

Video, narration, and music services return separate assets. StellaStudios passes those assets through subtitle generation, audio mixing, watermarking, and FFmpeg assembly to produce one video file.

The project has a modular pipeline for metadata generation, media processing, assembly, and archiving. The scheduled publishing cycle is currently paused, so the architecture should not be read as a live unattended publishing service.

why this matters

The pipeline handles the handoffs between generation, narration, subtitles, audio processing, and assembly. That reduces manual file handling, although generated assets still need review and the workflow has known reliability limits.

Human review remains an important production control. The current source review does not establish that a one-hour approval window or automatic publishing is actively operating, so those should not be treated as available production guarantees.

pipeline stages
01 - Generation
Script and video footage generated via a Sora-class model, driven by the day's content brief.
02 - Score
Background music generated via Suno, matched to the tone and length of the generated footage.
03 - Voice + timestamps
Narration synthesized via ElevenLabs, which returns word-level timestamps alongside the audio - the sync backbone for every stage after this one.
04 - Subtitle generation
Subtitles are built directly from the ElevenLabs word-level timestamps rather than a separate transcription pass - captions land exactly on the spoken word, not an approximated guess.
05 - Mix & master (ffmpeg)
Narration, music, and any source audio are mixed and mastered to a consistent loudness target.
06 - Watermark burn-in
Brand watermark is composited directly into the final video frame, not added as a removable overlay layer.
07 - Review hold (1 hour)
Finished video sits in a review queue for one hour before publish - the one manual checkpoint in an otherwise unattended pipeline.
08 - Auto-publish → dormant
Uploads automatically once the review window clears, then the pipeline goes fully dormant until the next scheduled wake at 12:00 UTC.
engineering detail

Sync is the whole problem

Each external service returns an artifact independently, so timing and consistency have to be handled during assembly. The inspected subtitle implementation distributes phrase-level cues across the measured narration duration; it does not use word-level speech timestamps as a guaranteed alignment source.

subtitle cue generation from word-level timestamps (conceptual)
// ElevenLabs returns per-word start/end offsets alongside the audio. // Subtitle cues are grouped from those offsets directly - // no separate speech-to-text pass, no drift to correct for. function buildCues(wordTimestamps, maxWordsPerCue = 8) { return chunk(wordTimestamps, maxWordsPerCue).map(group => ({ start: group[0].start, end: group.at(-1).end, text: group.map(w => w.word).join(' ') })); }
mastering + watermark burn-in (illustrative ffmpeg pass)
ffmpeg -i narration.wav -i score.wav -filter_complex \ "[0:a]loudnorm=I=-16:TP=-1.5[voice]; [1:a]volume=0.25[music]; [voice][music]amix=inputs=2:duration=first[mixed]" \ -i footage.mp4 -i watermark.png -filter_complex \ "[2:v][3:v]overlay=W-w-24:H-h-24[branded]" \ -map "[branded]" -map "[mixed]" output_final.mp4

External generation stages can take different amounts of time or fail. The pipeline is split into specialized nodes, but some stages independently discover the latest metadata or use shared pending directories. That creates a cross-run mix-up risk under concurrent execution and is a clear target for stronger per-job isolation and recovery logic.

status

Currently dormant - the daily 12:00 UTC wake-and-publish cycle is paused. Built and validated end-to-end, from generation through the one-hour human review hold to publish; ready to resume on a new schedule or client brief.

same discipline, different domain

Gating publish behind a review window mirrors StellaSnipes' flagged-for-review queue for unverifiable domains - both treat "automated" and "unsupervised" as different things. The wake/dormant scheduling here is the same shape as StellaFlips' hourly lock cycle: don't do expensive work more often than the situation actually calls for.
